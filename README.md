# Adaptable, Incremental, and Explainable Network Intrusion Detection Systems for Internet of Things
## Code and Data

This repository extends the published EAAI work on adaptable, incremental, and explainable IoT intrusion detection. It contains the code, data samples, and saved experiment outputs used to study source-to-target adaptation, continual learning, and SHAP-based explainability in the same NIDS setting.
